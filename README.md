# ภูเขาเส้นเดียว (mountain-mygame)

ไอเดียเกมส่วนตัวของพี่กัน — ภาพตัดขวาง 2 มิติ ภูเขาสูงเส้นเดียว
บ้านยื่นออกจากไหล่เขาบนเสาค้ำที่ผู้เล่นลากเอง และถ้ำที่ขุดลึกลงไปเรื่อย ๆ พร้อมไม้ค้ำยัน

> **สถานะ: ไอเดียกับภาพร่างเท่านั้น ยังไม่มีตัวเกม ยังไม่มีเลขรุ่น**

## ในภาพร่างมีอะไร

- ภูเขาสูงชันเส้นเดียว ยอดเกือบชนขอบบน
- บ้าน 3 หลังบนไหล่เขา ตั้งบนเสาค้ำที่เอียงไม่เท่ากันเหมือนลากวางเอง
- บ้านมีห้องต่อเติม ต้นไม้ที่บ้าน ลังใส่ของ เสาสัญญาณบนหลังคา
- สายไฟเชื่อมทุกหลัง ผ่านเสาไฟบนยอดเขา · หลังบนสุดมีโซล่าเซลล์
- ถ้ำ 3 ชั้น มีไม้ค้ำยัน บันได ปล่องจากบ้านลงถ้ำ และขุดลึกต่อไปได้
