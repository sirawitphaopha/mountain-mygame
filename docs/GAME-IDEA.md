# ไอเดียเกม ภูเขาเส้นเดียว

> ร่างครั้งแรก 26 ต.ค. 2569 · ยังเป็นไอเดีย ยังไม่มีตัวเกม · พี่กันจะต่อยอดไปเรื่อย ๆ
> ภาพร่างอยู่ที่ [`sketch.html`](../sketch.html) (เปิดในเบราว์เซอร์ได้เลย)

ในไฟล์นี้แยกไว้ชัดเจนว่าอะไร **พี่กันเคาะแล้ว** อะไร **แคลร์เสนอ ยังไม่มีใครเคาะ**

---

## 1. ที่มา

เกิดจากรูปที่พี่กันวาดเล่นบนกระดาษ
วาด **เส้นภูเขาเส้นเดียวกลางกระดาษ** แล้ววาดบ้านต่อขึ้นมาจากพื้นภูเขา มีเสาค้ำยัน
แล้วเจาะถ้ำลงไปในภูเขา ถ้ำมีไม้ค้ำยัน และเจาะลึกลงไปเรื่อย ๆ

พี่กันบอกเองว่าพอนั่งคิดไป **คล้ายเกมสร้างเมือง city-lab แต่เปลี่ยนมาเป็นสองมิติ**

---

## 2. ภาพในหัวของพี่กัน (✅ พี่กันเคาะแล้ว จากการแก้ภาพร่าง 4 รอบ)

| เรื่อง | ภาพในหัวพี่กัน | ได้มาจากรอบไหน |
|---|---|---|
| มุมมอง | ภาพ 2 มิติ ผ่าภูเขาให้เห็นด้านข้าง เหนือเส้นคือท้องฟ้า ใต้เส้นคือเนื้อภูเขา | ไอเดียตั้งต้น |
| ภูเขา | **ภูเขาสูงชัน** ยอดสูงเกือบชนขอบบน ไม่ใช่เนินเตี้ย | รอบ 2 |
| บ้าน | สร้างต่อขึ้นมาจากพื้นภูเขา ยื่นออกจากไหล่เขา | ไอเดียตั้งต้น |
| เสาค้ำยันบ้าน | **ไม่เรียงสวย** เหมือนผู้เล่นลากเองจากฐานบ้านไปจิ้มที่พื้นเขา เสาเอียงไม่เท่ากัน และต้องเด่นในภาพ | รอบ 2 + รอบ 3 |
| ต่อเติม | บ้านมีส่วนต่อเติม | รอบ 2 |
| ต้นไม้ | **อยู่ที่บ้าน ไม่ใช่บนภูเขา** | รอบ 3 |
| ลังใส่ของ | มีลังเก็บของที่บ้าน | รอบ 2 |
| เสาสัญญาณ | บนหลังคาบ้านมีของคล้ายเสาสัญญาณ | รอบ 3 |
| สายไฟ | **มีสายไฟเชื่อมแต่ละหลัง** | รอบ 4 |
| โซล่าเซลล์ | **มีหลังหนึ่งที่มีโซล่าเซลล์** | รอบ 4 |
| ถ้ำ | เจาะลงในภูเขา มีไม้ค้ำยัน เจาะลึกลงไปเรื่อย ๆ | ไอเดียตั้งต้น |

### ของที่แคลร์ใส่ในภาพร่างเอง (พี่กันยังไม่ได้พูดถึง)

- บ้าน 3 หลัง (ซ้ายกลางเขา บนใกล้ยอด ขวาล่าง)
- ห้องต่อเติมแบบต่าง ๆ: เพิงข้างบ้าน ห้องชั้นสองบนหลังคา ห้องติดข้างบ้าน ระเบียง
- ปั้นจั่นหย่อนลังที่บ้านหลังขวา
- เสาไฟไม้บนยอดเขา ให้สายไฟข้ามจากฝั่งซ้ายไปฝั่งขวาได้
- ปล่องจากใต้พื้นบ้านหลังบนลงไปถึงถ้ำ
- ถ้ำ 3 ชั้น บันไดลงชั้นล่าง คนขุด ห้องถ้ำมีตะเกียง ลูกศรบอกว่าขุดต่อลงไปได้

---

## 3. เกมจะเล่นยังไง (💭 แคลร์เสนอ ยังไม่มีใครเคาะ)

### 3.1 วงจรหลัก — สร้างบ้านบนเขา แล้วขุดลงไปหาของมาสร้างต่อ

1. **ขุดถ้ำลงไป** เจอหิน แร่ ของเก่าฝังดิน ยิ่งลึกยิ่งเจอของดี
2. **ขนของขึ้นมา** ด้วยบันได ปล่อง หรือปั้นจั่น เก็บใส่ลัง
3. **เอาของมาต่อเติมบ้าน** เพิ่มห้อง เพิ่มชั้น ยื่นพื้นออกไปไกลขึ้น
4. บ้านใหญ่ขึ้น ก็ขุดได้ลึกขึ้น วนกลับไปข้อ 1

### 3.2 ของแต่ละชิ้นในภาพทำหน้าที่อะไรในเกม

| ของในภาพ | หน้าที่ในเกม |
|---|---|
| เสาค้ำที่ลากเอง | **หัวใจของเกม** ผู้เล่นลากเสาจากใต้พื้นบ้านไปจิ้มพื้นเขาเอง ค้ำไม่พอบ้านเอียง ร้าว หรือพัง เสาของแต่ละคนจึงเบี้ยวไม่เหมือนกัน ตรงกับภาพในหัวพี่กัน |
| ไม้ค้ำในถ้ำ | ขุดยาวแล้วไม่ค้ำ เพดานถล่ม ต้องค้ำเป็นช่วง ๆ |
| ต้นไม้ที่บ้าน | แหล่งไม้สำหรับทำเสาค้ำ ปลูกที่บ้าน ตัดแล้วรอโตใหม่ ไม้จึงมีจำกัด ต้องเลือกว่าจะใช้ค้ำบ้านหรือค้ำถ้ำ |
| ลังใส่ของ | ที่เก็บของที่ขุดได้ ลังเต็มต้องสร้างเพิ่ม และลังหนักก็กดน้ำหนักลงพื้นบ้าน |
| โซล่าเซลล์ + สายไฟ | ไฟฟ้าใช้จุดตะเกียงในถ้ำลึกที่มืด และหมุนปั้นจั่น บ้านที่ไม่มีสายไฟเชื่อมใช้ไฟไม่ได้ |
| เสาสัญญาณ | รับข่าวพายุหรือแผ่นดินไหวล่วงหน้า หรือรับคำขอแลกของจากที่อื่น |

### 3.3 อะไรทำให้ตื่นเต้น

- พายุ ฝน แผ่นดินไหว มาเป็นช่วง ๆ ทดสอบว่าเสาที่ผู้เล่นลากไว้แข็งแรงพอไหม
- บ้านยิ่งต่อเติมยิ่งหนัก อยากต่อให้ใหญ่ แต่ต้องค้ำให้ทัน

### 3.4 ทางที่ยังต้องเลือก — อารมณ์ของเกม

| แบบ | เป็นยังไง |
|---|---|
| แบบชิล | สร้างเพลิน ๆ ดูบ้านโตขึ้นเรื่อย ๆ พังได้บ้างแต่ไม่แพ้ |
| แบบท้าทาย | ของจำกัด ภัยมาเรื่อย ๆ พังหนักอาจต้องเริ่มใหม่ |

แคลร์เอียงไปทาง **แบบชิลที่มีฟิสิกส์นิด ๆ** เพราะภาพที่พี่กันวาดดูเป็นบ้านที่ค่อย ๆ โตจากการต่อเติม มากกว่าเกมเอาตัวรอด · **ยังรอพี่กันเคาะ**

---

## 4. ต่างจากเกมสร้างเมืองทั่วไปตรงไหน (💭 แคลร์เสนอ)

- **โตขึ้นข้างบนกับลงข้างล่าง ไม่ได้แผ่ออกด้านข้าง** มีเส้นภูเขาเส้นเดียว ที่ว่างมีแค่ยื่นออกจากหน้าผากับขุดลงไปในเขา ทุกตารางนิ้วมีค่า
- **เห็นข้างในทั้งหมดในภาพเดียว** บ้าน เสาค้ำ สายไฟ ถ้ำ คนขุด อยู่จอเดียวกัน เหมือนดูรังมดหรือบ้านตุ๊กตาผ่าครึ่ง
- **มีแรงโน้มถ่วงให้คิด** บนเขาชัน ทุกอย่างที่ต่อเติมต้องมีอะไรค้ำ
- **เล็กลง ใกล้ตัวขึ้น** จากทั้งเมืองเหลือไม่กี่หลังบนภูเขาลูกเดียว

แคลร์มองว่าเป็นเกมแยกของมันเองได้ ไม่ต้องเป็นส่วนหนึ่งของ city-lab

---

## 5. คำถามที่ยังเปิดอยู่

1. ผู้เล่นเป็นคนวาด/กดสร้างทีละชิ้นเอง หรือมีตัวละครเดินขุดเอง
2. เสาค้ำกับไม้ค้ำมีผลจริง (ไม่ค้ำแล้วพัง) หรือเป็นของประดับ — แคลร์เสนอให้มีผลจริง
3. ขุดลงไปเพื่ออะไร เจอแร่ เจอของ เจอโลกข้างใต้ หรือขุดเพราะสนุกที่เห็นถ้ำโต
4. หน้าตาเกมเป็นลายเส้นวาดมือบนกระดาษเหมือนภาพร่าง หรือภาพสีเต็ม
5. อารมณ์ของเกม ชิลหรือท้าทาย (ข้อ 3.4)
6. มีคนอาศัยในบ้านไหม กี่คน
